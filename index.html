Arduino & Servomotor Hardware Koppeling

Met SortCycle kun je rechtstreeks een Arduino Uno, Nano of ESP32 via de USB-kabel aansturen! Wanneer de AI een item herkent, stuurt de browser een serieel commando (bijv. BIN:PLASTIC) waardoor een servomotor fysiek naar de juiste klep draait.

[Status] Seriële monitor gereed. Klik op 'Arduino Koppelen' om de COM-poort te kiezen.
/* SortCycle - Arduino Servo & LED Controller voor Slimme Afvalbak Geschikt voor Arduino Uno / Nano / Mega / ESP32 */ #include <Servo.h> Servo sortServo; const int SERVO_PIN = 9; const int LED_PLASTIC = 4; const int LED_STATIEGELD = 5; const int LED_PAPIER = 6; const int LED_OVERIG = 7; void setup() { Serial.begin(9600); sortServo.attach(SERVO_PIN); sortServo.write(0); // Ruststand pinMode(LED_PLASTIC, OUTPUT); pinMode(LED_STATIEGELD, OUTPUT); pinMode(LED_PAPIER, OUTPUT); pinMode(LED_OVERIG, OUTPUT); Serial.println("SortCycle Arduino Online! Wachten op commando's..."); } void loop() { if (Serial.available() > 0) { String command = Serial.readStringUntil('\n'); command.trim(); command.toUpperCase(); // Schakel alle leds eerst uit digitalWrite(LED_PLASTIC, LOW); digitalWrite(LED_STATIEGELD, LOW); digitalWrite(LED_PAPIER, LOW); digitalWrite(LED_OVERIG, LOW); if (command == "BIN:PLASTIC") { digitalWrite(LED_PLASTIC, HIGH); sortServo.write(45); delay(2500); sortServo.write(0); } else if (command == "BIN:STATIEGELD") { digitalWrite(LED_STATIEGELD, HIGH); sortServo.write(90); delay(2500); sortServo.write(0); } else if (command == "BIN:PAPIER") { digitalWrite(LED_PAPIER, HIGH); sortServo.write(135); delay(2500); sortServo.write(0); } else if (command == "BIN:OVERIG") { digitalWrite(LED_OVERIG, HIGH); sortServo.write(180); delay(2500); sortServo.write(0); } } }
💡 Tip voor je presentatie: Sluit een standaard SG90 servomotor aan op Pin 9 (Bruin=GND, Rood=5V, Oranje=Pin 9) en plak een pijltje of klepje op de servo. Wanneer je een blikje voor de webcam houdt, beweegt de fysieke servo automatisch mee!
