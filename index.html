BPMN 2.0 Spiekbrief & HHS Richtlijnen

Conform de BPMN-Reader Haagse Hogeschool HBO-ICT (Paul de Vries) & Agevo

1

Basis Symbolen (Hoofdstuk 2)

  • Taak (Task): Rechthoek met ronde hoeken. Atomair (niet verder gedetailleerd). Naam: zelfstandig naamwoord + infinitief/imperatief werkwoord (bijv. Plank pakken, Klant controleren).
  • Start Event: Enkelvoudige dunne cirkel. Geen markering binnen de cirkel. Mag nooit een inkomende sequence flow hebben. Naam beschrijft de gebeurtenis (nooit 'Het proces start').
  • End Event: Enkelvoudige dikke cirkel. Geen markering binnen de cirkel. Mag nooit een uitgaande sequence flow hebben. Naam in voltooide tijd (bijv. Order is uitgeleverd).
  • Sequence Flow: Doorgetrokken lijn met één pijl. Bepaalt de volgorde van taken binnen één proces.
2

Gateways & Exception Issue (Hoofdstuk 2 & 3)

  • Exclusive Gateway (XOR - X): Slechts één conditie is waar. Voorafgegaan door een control task die de conditie vaststelt. Minimaal 2 uitgaande conditional flows.
  • Inclusive Gateway (IOR - O): Eén of elke combinatie van condities kan waar zijn. Minimaal 1 en maximaal alle flows gaan door. Merge IOR aanbevolen.
  • Parallel Gateway (AND - +): Alle uitgaande stromen worden gelijktijdig uitgevoerd. Geen control task vooraf vereist. Een AND-join wacht tot álle binnenkomende taken klaar zijn.
  • Default Flow (Schuin streepje \): Nooduitgang voor het gateway exception issue: treedt in werking als geen enkele conditie waar is om stagnatie te voorkomen.
3

Data Objects & Data Store (Hoofdstuk 4)

  • Data Object: Pagina met ezelsor. Tijdelijke data tijdens het proces. Toestand tussen rechte haken: Brief [draft], Brief [verbeterd].
  • Data Store: Trommel met deksel. Permanente opslag (database, archief). Blijft bewaard na het proces.
  • Associaties: Stippellijn met pijl. Naar de taak = data input (lezen). Naar het object/store = data output (schrijven).
  • Verboden regel (Figuur 26): Data objects mogen NOOIT rechtstreeks gekoppeld worden aan een data store (moet altijd via een taak lopen!).
  • Netto data: Als slechts een deel van een data store gebruikt wordt, noteer dit als annotatie op de associatie (bijv. Dagomzet).
4

Pools, Lanes & Sub Process (Hoofdstuk 5)

  • Pool: Eén organisatie met eigen aansturing. Kan White Box (interne taken zichtbaar) of Black Box (gesloten extern) zijn.
  • Swimlane (Lane): Organisatorische functie / rol / afdeling binnen een pool. Sequence flows mogen vrij tussen lanes binnen dezelfde pool bewegen.
  • Verboden regel (Figuur 36): Sequence flows mogen NOOIT de grens tussen twee pools overschrijden!
  • Message Flow (onderbroken streepjeslijn met pijl): Uitsluitend toegestaan tussen twee verschillende pools. Nooit tussen taken binnen dezelfde pool!
  • Sub process [+]: Rechthoek met [+] markering. Houdt details buiten zicht en bevat bij inzoomen een eigen BPMN-deelproces.
